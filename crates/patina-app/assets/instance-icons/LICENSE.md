# Instance icons

The 24 pixel-art PNG icons in this directory (all except `neoforge.png`,
`forge.png`, and `fabric.png`) come from the **Voxel Pack** by Kenney
(Kenney Vleugels, www.kenney.nl).

- Sources: https://kenney.nl/assets/voxel-pack and the same pack as uploaded
  by Kenney on OpenGameArt, https://opengameart.org/content/voxel-pack
- Author: Kenney (www.kenney.nl)
- License: Creative Commons Zero, CC0 1.0 Universal
  (https://creativecommons.org/publicdomain/zero/1.0/)
- Modification: scaled to 64×64 by Patina (nearest-neighbor, so the pixel
  style is kept).

Credit is not required by CC0; it is given here anyway.
